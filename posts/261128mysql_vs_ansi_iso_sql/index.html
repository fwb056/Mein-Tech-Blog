MySQL vs ANSI/ISO 표준 SQL 핵심 문법 요약표

2026-11-28

1. 식별자 및 연산자 규칙

구분 ANSI/ISO 표준 SQL MySQL (기본 설정) 비고
식별자(테이블/컬럼명) 감싸기 큰따옴표 ("table_name") 백틱 (`table_name`) MySQL은 기본적으로 "를 문자열 리터럴로 취급
문자열 리터럴 작은따옴표 ('text') 작은따옴표 ('text') 또는 큰따옴표 ("text") 호환성을 위해 작은따옴표(') 사용 권장
문자열 연결 || 연산자 ('A' || 'B') CONCAT('A', 'B') MySQL에서 ||는 기본적으로 논리 연산자 OR
논리 부정 <> (다르다) != 또는 <> 표준 호환을 위해 <> 사용 권장

2. 테이블 정의 (DDL) 및 자료형

구분 ANSI/ISO 표준 SQL MySQL 비고
자동 증가 키 GENERATED ALWAYS AS IDENTITY AUTO_INCREMENT MySQL은 표준 IDENTITY 문법 미지원
가변 문자열 CHARACTER VARYING(n) VARCHAR(n) MySQL도 CHARACTER VARYING을 별칭으로 허용
논리형 (Boolean) BOOLEAN (TRUE / FALSE) TINYINT(1) (1 / 0) MySQL에서 BOOLEAN 선언 시 내부적으로 TINYINT(1)로 변환
날짜 및 시간 TIMESTAMP DATETIME 또는 TIMESTAMP MySQL TIMESTAMP는 타임존 변환 지원, DATETIME은 입력값 그대로 저장
제약 조건 이름 생략 외래 키 선언 시 이름 생략 가능 FOREIGN KEY (...) REFERENCES ... 외래 키 삭제(DROP)를 위해 CONSTRAINT fk_name 명시 권장

3. 데이터 조회 및 조작 (DML)

구분 ANSI/ISO 표준 SQL MySQL 예시 (MySQL 기준)
조회 개수 제한 (페이징) FETCH FIRST 10 ROWS ONLY LIMIT 10 (또는 LIMIT offset, count) SELECT * FROM items LIMIT 10 OFFSET 20;
조건부 삽입/수정 (UPSERT) MERGE INTO ... INSERT ... ON DUPLICATE KEY UPDATE 중복 키 발생 시 UPDATE 구문 실행
다중 행 삽입 INSERT INTO t VALUES (...), (...) INSERT INTO t VALUES (...), (...) 표준과 동일하게 지원
테이블 결합 (JOIN) INNER JOIN, LEFT OUTER JOIN INNER JOIN, LEFT JOIN 표준 JOIN 문법 완벽 지원 (OUTER 키워드 생략 가능)

4. 자주 쓰는 내장 함수 대조표

기능 ANSI/ISO 표준 SQL MySQL 전용 단축 함수 권장 사항
NULL 값 대체 COALESCE(col, '기본값') IFNULL(col, '기본값') MySQL도 COALESCE 지원 (표준 사용 권장)
조건 분기 CASE WHEN ... THEN ... END IF(조건, 참, 거짓) 단순 2분기 외에는 표준 CASE 문 권장
현재 날짜/시간 CURRENT_TIMESTAMP NOW() MySQL도 CURRENT_TIMESTAMP 지원
형변환 (Casting) CAST(col AS VARCHAR(10)) CAST(col AS CHAR(10)) / CONVERT() MySQL CAST에서는 VARCHAR 대신 CHAR 사용
문자열 자르기 SUBSTRING(col FROM 1 FOR 3) SUBSTRING(col, 1, 3) 콤마(,) 방식이 직관적이나 표준 구문도 지원

5. 동작 방식 및 SQL Mode 주의사항

  • 문자열 대소문자 구분 (Collation)
    • 표준 SQL 계열(Oracle, PostgreSQL 등): 기본적으로 대소문자를 구분합니다 ('Apple' <> 'apple').
    • MySQL: 기본 문자셋(utf8mb4_0900_ai_ci 등 _ci로 끝나는 설정)에서는 대소문자를 구분하지 않습니다. 구분이 필요하면 BINARY 연산자나 _cs / _bin Collation을 지정해야 합니다.
  • 엄격 모드 (STRICT_TRANS_TABLES)
    • 최신 MySQL(8.0 이상)은 기본적으로 엄격 모드가 활성화되어 표준 SQL처럼 데이터 타입 불일치나 길이 초과 시 에러를 발생시킵니다. 구버전 설정에서는 경고를 띄우고 데이터를 잘라서 저장할 수 있으므로 주의해야 합니다.
  • ANSI 호환 모드 활성화
    • 세션이나 설정에서 SET sql_mode = 'ANSI';를 실행하면 큰따옴표(")를 식별자로 인식하고 ||를 문자열 연결로 처리하는 등 표준 SQL에 가깝게 동작하도록 변경할 수 있습니다.
