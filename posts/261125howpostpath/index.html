Astro에서 마크다운(Markdown) 게시글 저장 경로와 URL 구조 이해하기

2026-11-25

Astro로 정적 기술 블로그를 구축할 때, 마크다운(.md) 게시글을 어디에 저장해야 하는지 그리고 그 파일이 어떤 웹 URL로 변환되는지는 Content Collections(콘텐츠 컬렉션) 규칙과 파일 기반 라우팅에 의해 결정됩니다.

핵심 설정이 이루어지는 세 가지 요소를 정리합니다.

1. 저장 폴더 이름을 정의하는 곳: src/content/config.ts

Astro는 기본적으로 src/content/ 디렉터리 내부를 콘텐츠 저장소로 탐색합니다. 이 상위 경로는 Astro의 기본 규약이며, 실제 게시글이 들어갈 하위 폴더 이름은 src/content/config.ts 파일의 collections 객체 키(Key) 이름으로 결정됩니다.

// src/content/config.ts
import { defineCollection, z } from 'astro:content';

const postsCollection = defineCollection({
  type: 'content',
  schema: z.object({
    title: z.string(),
    pubDate: z.date(),
    description: z.string().optional(),
    draft: z.boolean().default(false),
  }),
});

export const collections = {
  // 키 이름이 'posts'이므로 'src/content/posts/' 폴더를 게시글 경로로 인식합니다.
  posts: postsCollection,
};
  • 만약 키 이름을 blog: postsCollection으로 변경하면, 실제 마크다운 저장 경로 역시 src/content/blog/로 바뀝니다.

2. 정의된 경로에서 글을 불러오는 곳: getCollection()

config.ts에서 지정한 컬렉션 이름은 실제 화면을 렌더링하는 .astro 페이지에서 getCollection() 함수를 호출할 때 인자로 전달됩니다.

  • 게시글 목록 페이지 (src/pages/index.astro)
import { getCollection } from 'astro:content';

// 'posts' 폴더 내의 마크다운 파일 중 비공개(draft: true)가 아닌 글만 조회
const publishedPosts = await getCollection('posts', ({ data }) => {
  return data.draft !== true;
});
  • 게시글 상세 페이지 (src/pages/posts/[slug].astro)
import { getCollection } from 'astro:content';

export async function getStaticPaths() {
  const posts = await getCollection('posts', ({ data }) => {
    return data.draft !== true;
  });
  // ...
}

3. 실제 웹사이트 URL 경로가 결정되는 곳: src/pages/

마크다운 파일이 저장되는 물리적 위치(src/content/posts/)와 별개로, 브라우저에서 접속하게 되는 URL 주소는 src/pages/ 디렉터리의 폴더 구조를 그대로 따릅니다.

구분 경로 위치 역할
원본 글 저장 src/content/posts/hello.md 실제 마크다운 원고가 위치하는 곳
라우팅 템플릿 src/pages/posts/[slug].astro 동적 경로([slug])를 받아 HTML로 변환하는 틀
최종 웹 URL https://도메인/posts/hello 사용자가 실제로 접속하는 페이지 주소

하위 폴더로 카테고리 정리하기

글이 많아져 src/content/posts/ 내부에 주제별 하위 폴더(예: src/content/posts/db/mysql-index.md)를 만들어 정리하더라도 별도의 설정 수정이 필요하지 않습니다. Astro가 하위 경로를 자동으로 slug에 포함하여 .../posts/db/mysql-index 형태의 URL을 자동으로 생성합니다.

요약

  1. 저장 위치 설정: src/content/config.ts의 collections 키 이름으로 src/content/<폴더명>/ 경로가 확정됩니다.
  2. 데이터 조회: 페이지 컴포넌트에서 getCollection('<폴더명>')을 호출해 마크다운 데이터를 가져옵니다.
  3. URL 결정: src/pages/ 아래에 배치된 [slug].astro 파일의 위치에 따라 최종 배포 URL 경로가 만들어집니다.
